This public edition was prepared on 2026-10-08 from reviewed local source snapshot `099cfa308fd11deec491b8ac9369814593eeef6e`. The organizer repository was populated through web uploads and has a different Git commit history; the local snapshot hash is not presented as its remote HEAD. The organizer-managed repository has not been modified by this export.

The original application modules, corpus builders, and development tests are retained. Public-edition changes are limited to:

- A portfolio README, evaluation summary, API documentation, and this provenance note.
- A fictional, locally runnable dataset and smoke checks.
- Local environment examples and stricter ignore patterns.
- Exclusion of submission checklists, the technical proposal, operational preflight script, private server addresses, credentials, generated indexes, and organizer-provided data.

The public Git history starts at this portfolio export. It does not reconstruct or backdate the original development history. Retaining the application code does not imply that the known financial accuracy issues have been fixed.
