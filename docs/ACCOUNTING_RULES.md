# 재무 수치 해석 규칙

이 문서는 외부 회계지식을 답변 근거로 추가하기 위한 자료가 아니다. 제공 공시에서 숫자를 선택하고 비교할 때 코드와 프롬프트가 지켜야 하는 검산 조건을 정리한다. 최종 사실 근거는 항상 코퍼스의 공시 원문과 접수번호다.

## 기간과 범위

- 재무상태표의 자산·부채·자본은 기준일 현재의 시점 수치다.
- 손익계산서와 현금흐름표는 시작일부터 종료일까지의 기간 수치다.
- 사업보고서는 연간, 반기보고서는 반기 누적, 3분기보고서는 9개월 누적을 기본값으로 읽는다.
- 질문이 `2분기`를 명시하면 반기보고서의 3개월 열을, `반기 기준`을 명시하면 6개월 누적 열을 사용한다.
- 연결과 별도 수치를 섞지 않는다. 질문이 범위를 명시하면 그 범위의 표만 사용한다.

## 숫자와 단위

- 표의 기수와 실제 회계연도를 대응시킨 뒤 해당 열을 선택한다.
- `원`, `천원`, `백만원`, `억원`을 숫자와 함께 저장하고 비교 전에 원으로 환산한다.
- 괄호 금액은 음수로 해석한다. 영업손실을 전기 영업이익으로 대체하지 않는다.
- 정정공시는 같은 사건의 최신 값으로 원공시를 대체하며 정정 전후를 합산하지 않는다.

## 관계와 계산

- `자산 = 부채 + 자본`은 동일 기준일·동일 연결범위·동일 단위의 세 값이 모두 있을 때 검산에만 쓴다.
- 차이는 `A - B`, 격차율은 `(A - B) / |B| × 100`으로 계산하고 B가 분모임을 표시한다.
- 증감률은 `(당기 - 전기) / |전기| × 100`이며 누적값과 단일분기값을 섞지 않는다.
- 비중은 `부분 / 전체 × 100`이다. 분자와 분모의 기간·통화·단위·연결범위가 같아야 한다.
- 서로 다른 자금용도는 같은 공시의 전체 조달 예정액을 물을 때만 합산한다. 계약총액과 계약금, 정정 전후 금액은 중복 합산하지 않는다.

## 사건 상태

- 증자·사채 `결정`은 예정 상태다. 납입·발행 완료 공시 없이 실제 조달 완료로 표현하지 않는다.
- 계약 체결일, 계약기간 시작일, 정정 접수일, 해지일을 구분한다.
- `특정 연도에 체결한 뒤 해지`는 해지공시의 관련공시 또는 본문에서 원계약 체결연도를 확인한 건만 포함한다.
- 검색되지 않은 유형은 `제공 근거에서 확인되지 않음`으로 표시하며 발생하지 않았다고 단정하지 않는다.
